# Fonts for lorin

Poppins Regular (400) and Bold (700), Latin subset WOFF2, downloaded from Google Fonts (fonts.gstatic.com) on 2026-11-03.
License: SIL Open Font License 1.1 (free for commercial use, embedding in video allowed).
The Lorin playbook names Poppins Bold and Normal as the digital/secondary font. The primary font, Neutraface Display Bold,
is used only inside the logo (we never set text in it, and never recreate the logo).
