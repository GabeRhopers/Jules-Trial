# Fonts for demo-home-services

Local copies (Latin subset, WOFF2) so renders never depend on fetching fonts at render time.

| File | Font | License |
|---|---|---|
| Poppins-700.woff2, Poppins-800.woff2 | [Poppins](https://fonts.google.com/specimen/Poppins) | SIL Open Font License 1.1 |
| Inter-Variable.woff2 (weights 100 to 900) | [Inter](https://fonts.google.com/specimen/Inter) | SIL Open Font License 1.1 |

For a client's licensed corporate font, put its WOFF2 files here only if the client's font license
allows embedding in video, and list the license in this table.
