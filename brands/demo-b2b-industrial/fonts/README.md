# Fonts for demo-b2b-industrial

Local copies (Latin subset, WOFF2) so renders never depend on fetching fonts at render time.

| File | Font | License |
|---|---|---|
| IBMPlexSansCondensed-600.woff2, IBMPlexSansCondensed-700.woff2 | [IBM Plex Sans Condensed](https://fonts.google.com/specimen/IBM+Plex+Sans+Condensed) | SIL Open Font License 1.1 |
| IBMPlexSans-Variable.woff2 (weights 100 to 700) | [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) | SIL Open Font License 1.1 |

For a client's licensed corporate font, put its WOFF2 files here only if the client's font license
allows embedding in video, and list the license in this table.
